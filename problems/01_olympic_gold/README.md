# 01 — Olympic Gold Medals

**Problem:**  
Write a query to find the number of gold medals per swimmer, considering only swimmers who have won **exclusively gold medals**.

**Approaches included:**
- Subquery-based solution
- CTE-based solution

**How to run locally**
1. Execute `schema.sql`
2. Execute `seed.sql`
3. Run either solution query

**Notes**
- Assumes one row per medal per event
